# Security policy

Show Picker Club runs at [showpicker.club](https://showpicker.club), with apps on
the App Store and the Roku Channel Store. Only the live service and the current
`main` branch are supported.

## Reporting a vulnerability

Email **patrick@patrickturner.net** with what you found and how to reproduce
it. Please don't open a public issue for a security problem, and please don't
test against other members' accounts or data — sign up for your own.

You'll get a reply within a few days. Fixes ship through a normal pull request,
and you're welcome to be credited in it.

The machine-readable version of this contact is
[`/.well-known/security.txt`](https://showpicker.club/.well-known/security.txt).
